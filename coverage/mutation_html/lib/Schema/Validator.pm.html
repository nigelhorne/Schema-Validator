  310: =head2 load_dynamic_vocabulary
  311: 
  312: =head3 PURPOSE
  313: 
  314: Downloads the complete Schema.org vocabulary from the official JSON-LD
  315: endpoint, parses it into class and property lookup tables, caches the raw
  316: JSON-LD locally, and returns the class table as a hashref.
  317: 
  318: The cache is considered fresh for C<cache_duration> seconds (default 24 hours).
  319: On network failure the function falls back to a stale cache rather than
  320: returning an empty result, and emits a C<carp> warning.
  321: 
  322: =head3 ARGUMENTS
  323: 
  324: All arguments are optional; defaults come from C<%Schema::Validator::config>.
  325: 
  326: =over 4
  327: 
  328: =item * C<cache_file> (optional, scalar) -- path to the local cache file.
  329: Defaults to C<$config{cache_file}> (CWD-relative).
  330: 
  331: =item * C<cache_duration> (optional, scalar) -- cache validity window in seconds.
  332: Defaults to C<$config{cache_duration}>.
  333: 
  334: =item * C<vocab_url> (optional, scalar) -- URL of the JSON-LD vocabulary endpoint.
  335: Defaults to C<$config{vocab_url}>.
  336: 
  337: =item * C<ua_timeout> (optional, scalar) -- LWP::UserAgent timeout in seconds.
  338: Defaults to C<$config{ua_timeout}>.
  339: 
  340: =back
  341: 
  342: Both zero-argument and named calling conventions are supported:
  343: 
  344:     load_dynamic_vocabulary();
  345:     load_dynamic_vocabulary(ua_timeout => 60);
  346: 
  347: =head3 RETURNS
  348: 
  349: A hashref mapping class labels (e.g. C<'Person'>) to their raw JSON-LD
  350: definition hashrefs from the C<@graph> array.
  351: 
  352: Returns an empty hashref C<{}> on all failure paths (network unreachable,
  353: no cache, JSON parse error).  Never throws.
  354: 
  355: =head3 SIDE EFFECTS
  356: 
  357: =over 4
  358: 
  359: =item * Populates C<%Schema::Validator::dynamic_schema> with class definitions.
  360: 
  361: =item * Populates C<%Schema::Validator::dynamic_properties> with property definitions.
  362: 
  363: =item * Creates or updates the local cache file on a successful download.
  364: 
  365: =item * Emits C<carp> warnings on network failures, I/O errors, or JSON
  366: parse errors.
  367: 
  368: =back

  371: 
  372: The module version of this function stores the cache relative to the process
  373: CWD.  Set C<$Schema::Validator::config{cache_file}> to an absolute path if
  374: your application changes directory between calls.
